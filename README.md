# Nexora ERP（联光 ERP）

[English](README.en.md) · [访问官网](https://zhangzzj2003.github.io/Nexora-Erp/zh-CN/) · [官网源码](docs/site/) · [中文开发文档](docs/development.zh-CN.md)

[![打开 Nexora 官网 · 查看 WebGL 业务连线与示例界面](docs/site/website-preview.jpg)](https://zhangzzj2003.github.io/Nexora-Erp/zh-CN/)

面向企业内部的桌面 ERP，将采购、仓库、销售、生产与业务财务连接到同一套可追溯的单据和库存流水。桌面端使用 Electron、Vue 3、TypeScript 与 Pinia，服务端使用 FastAPI、SQLAlchemy 与 SQLite。

当前处于**单公司、多仓库、在线局域网内部试用阶段**。Windows 和 macOS 客户端通过 HTTPS 访问服务端，数据集中保存；断网后不能提交业务修改。文档和官网提供中英文版本，应用界面目前仍为中文。官网预览通过 GitHub Pages 发布，展示使用示例数据，不连接正式 ERP 服务。

桌面顶部采用融合标题栏：macOS 保留左上角原生红黄绿按钮，Windows 保留右上角原生窗口按钮；品牌、刷新、主页、当前分类与页面目录和主题切换在同一行。页面标签在标题栏下方、侧栏右侧独占一行，不随业务内容滚动。顶部空白处可拖动窗口，主题切换同步 Windows 控件配色；引导、登录和工作台共用顶部栏。普通浏览器预览与 Linux 保留系统窗口外框，关闭窗口仍遵循既有托盘行为。

右上角齿轮打开公共设置侧栏，可即时选择浅色/深色主题、简体中文/English，新增青绿（默认）、海蓝、靛蓝、紫罗兰、琥珀、玫红六组主题色预设，适配明暗模式，并同步公共按钮、焦点边框、下拉选项和导航选中态。明暗模式、主题色及语言分别自动保存在本机，退出登录后仍保留；存储不可用时当前窗口仍可切换，损坏的颜色偏好回退青绿。业务状态提示与图表分类颜色保留原有含义。设置侧栏支持点击遮罩、关闭按钮和 Esc 关闭，键盘焦点限定在侧栏内，关闭后回到入口。浏览器和 Linux 的引导、登录与工作台同样提供设置入口；窄窗口侧栏宽度不超过视口。语言目前覆盖设置、登录、服务端引导、工作台公共导航及 Naive UI 内置控件；业务表单、业务数据、角色名称和未翻译的服务端反馈仍保留原文。切换语言不刷新页面、不清空当前输入，也不改变路由和权限。

主题按钮采用太阳/月亮变形与 450 毫秒圆形过渡：明暗两个方向都从实际触发按钮的点击位置展开新画面；键盘操作以按钮中心为圆心。圆心与半径统一使用百分比，适配 Retina 等高分屏的实时合成裁剪，并在覆盖最远角后结束快照，避免半途闪满窗口。快照期间暂停控件和伪元素的过渡，避免新画面持续变色及中途闪跳；动画由浏览器计时，不固定为 30 帧。主题入口统一放在顶部，移除侧栏左下角开关；连续点击保留最后选择；不支持画面快照、开启“减少动态效果”或快照失败时直接更新主题。动效参考 Vben，许可说明见 [第三方声明](docs/third-party-notices.md)。

顶部目录跟随当前页面，并提供有权限的同分类页面下拉入口。刷新先重新读取有权访问的数据，再重载当前业务页，不重新初始化窗口，保留登录状态和已打开标签；独立分页和首页统计也会重新加载。刷新期间禁用重复点击与业务提交，失败通过公共消息提示，可再次重试。浏览器和 Linux 工作台在内容顶部提供同一组入口。

## 项目功能

| 业务领域 | 当前功能 |
| --- | --- |
| 账号与权限 | 用户、内置及自定义角色、单据操作授权、账号启停、密码重置、权限树与菜单图标配置。 |
| 基础资料 | 电子生产物料分类、详细参数及按子类自动编码；供应商、客户、仓库和供货关系，供应商列表支持服务端分页。 |
| 采购 | 采购申请审批与拆单、订单、分批收货、仓库确认入库、退货待出库确认及冲销。 |
| 仓库 | 多仓库存、其他入出库、调拨、盘点、异人审批的库存调整、来源流水与库存台账；[库存预警](docs/inventory-warnings.md) 按仓库阈值识别当前缺货与低库存，保留版本和修订证据；[实物批次基础](docs/physical-lot-tracing.md) 提供旧库存未识别期初、批次差额与来源历史核对，采购入库和其他入库确认可逐行登记实物批次，其他用途出库、采购退货、销售出库和仓库调拨可逐行选择已有批次，盘点差异和库存调整可逐行归入实物批次。 |
| 销售 | [客户关系与报价](docs/customer-relations.md) 的联系人、跟进、商机、独立审核转单及已批准报价 PDF 导出，客户新增相似提示与客户名称、联系人、商机 CSV 导入及手工概率加权预测；订单、分批出库、关联退货与冲销；确认时核对订单余量与库存。 |
| 生产 | BOM 版本、工单需求快照、分批领退料、报工、基础质检与合格成品批次入库；[MRP](docs/material-planning.md) 提供日期净需求、固定快照、独立审核与转单草稿；[设备维护](docs/equipment-maintenance.md) 提供台账、日历及人工运行小时保养、独立执行验收、停机与耗材来源。 |
| 成本与业务财务 | 库存移动平均、缺价人工核价、材料/人工/制造费用归集、完工成本分摊、应收应付来源及手工收付款与冲销。 |
| 总账 | 科目、期间、正式期初独立审核/确认、手工及业务来源凭证独立审核/过账/冲销、已过账科目明细和试算平衡；按序结账、倒序重开及历史余额/成本证据归档。 |
| 报表与运行 | 基础采购/库存报表及 CSV；[首页真实经营统计](docs/home-statistics.md) 按权限展示业务净额、趋势与当前待办/库存；局域网发现、证书指纹信任、系统服务、备份恢复和升级备份。 |

库存及金额变更保留来源、操作者和更正记录，确认与流水在同一事务内提交。缺价显示待核价，不以零代替未知金额；人工收付款和基础质检不表示已完成银行或现场实物核验。

| 业务扩展 | 计划 | 有限产能排产、完整质量体系、售后深化、CRM 深化、设备深化、人力及多组织。 |

## 开发入口

需要 Node.js 22.12+、Python 3.11+。环境配置、架构、业务约束、验证、**构建说明**、备份恢复和官网发布已移到详细开发文档：

- [中文开发文档](docs/development.zh-CN.md)
- [English development guide](docs/development.en.md)

运行 `npm run docs:build` 生成可本地查看的 HTML 官网和双语开发文档。官网通过 GitHub Pages 手动发布，完整动效从本文顶部的官网入口打开。安装包产物在 `release/`，尚未签名或公证；详细命令见开发文档。

物料档案、分类前缀、自动编号与旧库兼容规则见 [物料管理规则](docs/material-catalog.md)。客户端和服务端须同步升级。
