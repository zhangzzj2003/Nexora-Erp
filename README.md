# Nexora ERP（联光 ERP）

[English](README.en.md) · [访问官网](https://zhangzzj2003.github.io/Nexora-Erp/zh-CN/) · [官网源码](docs/site/) · [中文开发文档](docs/development.zh-CN.md)

[![打开 Nexora 官网 · 查看 WebGL 业务连线与示例界面](docs/site/website-preview.jpg)](https://zhangzzj2003.github.io/Nexora-Erp/zh-CN/)

面向企业内部的桌面 ERP，将采购、仓库、销售、生产与业务财务连接到同一套可追溯的单据和库存流水。桌面端使用 Electron、Vue 3、TypeScript 与 Pinia，服务端使用 FastAPI、SQLAlchemy 与 SQLite。

当前处于**单公司、多仓库、在线局域网内部试用阶段**。Windows 和 macOS 客户端通过 HTTPS 访问服务端，数据集中保存；断网后不能提交业务修改。文档和官网提供中英文版本，应用界面目前仍为中文。官网预览通过 GitHub Pages 发布，展示使用示例数据，不连接正式 ERP 服务。

桌面顶部采用融合标题栏：macOS 保留左上角原生红黄绿按钮，Windows 保留右上角原生窗口按钮；品牌、刷新、主页、当前分类与页面目录和主题切换在同一行。页面标签在标题栏下方、侧栏右侧独占一行，不随业务内容滚动。顶部空白处可拖动窗口，主题切换同步 Windows 控件图标配色；Windows 控件使用透明背景，透出页面顶部栏、底部分隔线和弹窗遮罩，避免右上角出现独立色块。引导、登录和工作台共用顶部栏。普通浏览器预览与 Linux 保留系统窗口外框，关闭窗口仍遵循既有托盘行为。

右上角齿轮打开公共设置侧栏，可即时选择浅色/深色主题、简体中文/English，新增青绿（默认）、海蓝、靛蓝、紫罗兰、琥珀、玫红六组主题色预设，适配明暗模式，并同步公共按钮、焦点边框、下拉选项和导航选中态。公共表格空状态图标的前景、底色与描边，以及账号头像底色、账号菜单和引导身份核对图标也同步切换主题色。明暗模式、主题色及语言分别自动保存在本机，退出登录后仍保留；存储不可用时当前窗口仍可切换，损坏的颜色偏好回退青绿。业务状态提示与图表分类颜色保留原有含义。Windows 设置面板从 48px 顶部栏下方展开，关闭设置按钮避开原生窗口控件。macOS 和 Windows 的应用内通知从顶部栏下方留出 12px 间距后显示，多条通知向下堆叠，避免遮挡设置、主题及原生窗口按钮。设置侧栏支持点击遮罩、关闭按钮和 Esc 关闭，键盘焦点限定在侧栏内，关闭后回到入口。浏览器和 Linux 的引导、登录与工作台同样提供设置入口；窄窗口侧栏宽度不超过视口。语言目前覆盖设置、登录、服务端引导、工作台公共导航及 Naive UI 内置控件；业务表单、业务数据、角色名称和未翻译的服务端反馈仍保留原文。切换语言不刷新页面、不清空当前输入，也不改变路由和权限。

主题按钮采用太阳/月亮变形与 450 毫秒圆形过渡：明暗两个方向都从实际触发按钮的点击位置展开新画面；键盘操作以按钮中心为圆心。圆心与半径统一使用百分比，适配 Retina 等高分屏的实时合成裁剪，并在覆盖最远角后结束快照，避免半途闪满窗口。快照期间暂停控件和伪元素的过渡，避免新画面持续变色及中途闪跳；动画由浏览器计时，不固定为 30 帧。主题入口统一放在顶部，移除侧栏左下角开关；动画启动前预先裁剪新快照，结束后保留全幅新画面直到完成绘制交接，再恢复常规样式，避免短暂露出旧主题；动画中再次切换会等待当前圆形完整展开，再接续最后一次选择，避免撤掉遮罩时突然跳色；捕获前取消无需等待超时。不支持画面快照、开启“减少动态效果”或快照失败时直接更新主题。动效参考 Vben，许可说明见 [第三方声明](docs/third-party-notices.md)。

物料单据弹窗统一复用 `WorkspaceDocumentDialog`：顶部标题与关闭区固定并用底色和分隔线区分，上方填写基础信息，下方使用公共物料表格，正文滚动时关闭和保存入口保持可见。已接入其他入库、仓库出库、调拨、盘点、库存调整、采购申请新建与修改、申请转单、采购订单、采购收货、采购退货、销售订单、销售出库、销售退货、BOM、生产领料与退料。可自由选料的单据通过“添加物料”新增表格行，在行内使用新版搜索选择器、查看资料和单位、编辑数量或移除，最多 100 行；其他入库数量框隐藏上下步进箭头，保留直接输入与原有数值校验；收货、退货、申请转单及领退料只处理来源单据明细，保留来源编号和数量上限，不开放自由新增。数量精度、盘点允许零、库存调整允许负数、单价和销售保修字段仍按各业务原规则处理；保存中禁止关闭和编辑，断线禁止编辑和保存。采购申请再次打开同一草稿保留输入，保存失败继续保留草稿。保存草稿不直接影响库存。所有 Naive UI 卡片弹窗共用固定关闭区，仅正文滚动；资料编辑器及非弹窗物料入口继续复用新版物料选择器。

“其他入库”列表的操作栏提供“查看详情”，所有单据状态均可打开公共单据弹窗的只读模式：上方展示基础信息及确认、取消、冲销记录，下方使用公共表格展示历史物料明细和已登记实物批次。详情不提供添加或保存操作，不影响新建草稿；拥有页面查看权限即可使用，断线时可查看已加载的快照。其他业务单据列表的详情入口尚未接入。

单据弹窗使用同一套顶部标题样式，新增和已接入的详情保留原正文与操作布局。十一类批次确认入口复用 `WorkspaceLotDialog` 与 `WorkspaceLotLineEditor`，包括采购入库、其他入库、仓库出库、调拨、盘点、调整、销售出库及退货、生产领退料与完工入库。批次按物料分组，以表格编辑和移除，实时核对应分配、已分配及剩余数量；长单据正文独立滚动，窄窗口表格横向滚动，标题和确认区保持可见。已有批次与新批次仍遵循各来源的字段、余额及确认规则，保存失败保留输入。

业务物料选择统一使用 `WorkspaceMaterialSelect`：下拉以两行展示编码、名称和关键规格，支持分类、规格、封装、品牌、制造商料号及技术参数搜索；核心资料默认展示，完整技术参数与备注按需展开。采购、仓库、销售、生产、供应商绑定和库存/报表筛选均沿用各自候选条件与权限；旧简要响应提示“详细资料暂不可用”。资料卡展示当前档案，不改写历史单据快照。生产 BOM 入口归入基础资料，新建版本复用公共单据弹窗，在明细表中选择组件、查看资料及编辑基准用量；保留原生产权限与工单版本引用。

顶部目录跟随当前页面，并提供有权限的同分类页面下拉入口。刷新先重新读取有权访问的数据，再重载当前业务页，不重新初始化窗口，保留登录状态和已打开标签；独立分页和首页统计也会重新加载。刷新期间禁用重复点击与业务提交，失败通过公共消息提示，可再次重试。浏览器和 Linux 工作台在内容顶部提供同一组入口。

## 项目功能

| 业务领域 | 当前功能 |
| --- | --- |
| 账号与权限 | 用户、内置及自定义角色、单据操作授权、账号启停、密码重置、权限树与菜单图标配置。 |
| 基础资料 | 生产 BOM 版本与组件用量；电子生产物料分类、详细参数及按子类自动编码；物料可搜索并绑定已有供应商或创建待完善供应商；供应商联系资料、完善状态、客户、仓库和供货关系，供应商列表支持服务端分页。 |
| 采购 | 采购申请审批与拆单、订单、分批收货、仓库确认入库、退货待出库确认及冲销。 |
| 仓库 | 多仓库存、其他入出库、调拨、盘点、异人审批的库存调整、来源流水与库存台账；[库存预警](docs/inventory-warnings.md) 按仓库阈值识别当前缺货与低库存，保留版本和修订证据；[实物批次基础](docs/physical-lot-tracing.md) 提供旧库存未识别期初、批次差额与来源历史核对，采购入库和其他入库确认可逐行登记实物批次，其他用途出库、采购退货、销售出库和仓库调拨可逐行选择已有批次，盘点差异和库存调整可逐行归入实物批次。 |
| 销售 | [客户关系与报价](docs/customer-relations.md) 的联系人、跟进、商机、独立审核转单及已批准报价 PDF 导出，客户新增相似提示与客户名称、联系人、商机 CSV 导入及手工概率加权预测；订单、分批出库、关联退货与冲销；确认时核对订单余量与库存。 |
| 生产 | 工单需求快照、分批领退料、报工、基础质检与合格成品批次入库；[MRP](docs/material-planning.md) 提供日期净需求、固定快照、独立审核与转单草稿；[设备维护](docs/equipment-maintenance.md) 提供台账、日历及人工运行小时保养、独立执行验收、停机、耗材出库、备件采购申请来源及设备与维护工单附件。 |
| 成本与业务财务 | 库存移动平均、缺价人工核价、材料/人工/制造费用归集、完工成本分摊、应收应付来源及手工收付款与冲销。 |
| 总账 | 科目、期间、正式期初独立审核/确认、手工及业务来源凭证独立审核/过账/冲销与[附件留存](docs/journal-attachments.md)、已过账科目明细和试算平衡；按序结账、倒序重开及历史余额/成本证据归档。 |
| 报表与运行 | 基础采购/库存报表及 CSV；[首页真实经营统计](docs/home-statistics.md) 按权限展示业务净额、趋势与当前待办/库存；局域网发现、证书指纹信任、系统服务、备份恢复和升级备份。 |

库存及金额变更保留来源、操作者和更正记录，确认与流水在同一事务内提交。缺价显示待核价，不以零代替未知金额；人工收付款和基础质检不表示已完成银行或现场实物核验。

### 单据编号

已支持 29 类核心单据及独立资金记录的服务端统一编号，提供拼音首字母 / 英文缩写和三种编号时区。新部署及旧库升级均由管理员首次登录通过居中的三步引导选择风格、时区并确认保存；历史补号与首次锁定同事务执行，已有参考号、批次及固定证据保留。详见 [单据编号规则](docs/document-numbering.md)。完整批次溯源页面仍待实现。

单据统一审批、生产关联查询与可选批次正在需求分支实施，当前已完成审批模板、共用事务基础及九类单据接入：其他入库、采购订单、采购收货、采购入库、采购退货、仓库出库、调拨、盘点和库存调整。采购各阶段分别审批，退货生成的出库草稿仍须独立批准；采购入库、其他入库、仓库出库、调拨、盘点和调整支持批准后的普通/可选实物批次操作，尚未完成全部 29 类业务入口接入或整体交付。普通入库仍须审批后执行，实物批次是否登记是独立选择。实施边界见 [审批与关联查询清单](docs/document-approval-and-links.md)。
