# 产品管理与 BOM 派生

## 已实现的一期范围

“基础资料 → 产品管理”（`/workspace/products`）提供服务端分页、产品建档、纳入已有物料、联合编辑、产品系列归组、具体配置名称、关联 BOM 与变更记录。产品不是另一套库存物料：`product_profiles.material_id` 唯一引用原物料，编码、名称、单位、规格、供应商、库存与所有业务单据继续使用同一身份。

产品类型为成品、半成品、组件或待分类。产品系列保存编码、名称、说明，只作归组，不记库存。一个产品最多归属一个系列；配置名称与系列选填，容量、颜色等仍通过原物料规格及扩展属性维护。新增产品与纳入已有物料是互斥的建档方式；新增物料、产品资料和审计在一个事务内保存。联合编辑同时校验产品版本及物料版本，任一冲突整笔回滚，保留界面草稿供核对。

页面展示区采用左右布局：左侧是“产品系列”，沿用原有机型档案和 `model_id` 归组；“全部产品”同时包含各系列及未归组产品。右侧按服务端分页显示产品配置卡片，默认选中当前页首项，切换产品后直接显示其 BOM 版本。系列切换清除旧搜索及旧产品读取，筛选重置保留当前系列；无结果或查询失败时不显示上一产品的 BOM。产品资料与变更记录保留公共详情弹窗。

新增、编辑产品将类型、系列与配置并入基本信息，沿用公共物料编辑器的分类、规格、单位和供应商校验。编辑器自行加载样式，直接进入产品页或从 BOM 快捷建档均可正常布局；正文滚动时标题、保存及取消按钮保持可见。窄窗口系列导航转为顶部排列，表单逐级减少列数。

数据库第 104 版增加 `product_models`、`product_profiles`、`product_changes`，并为 BOM 增加 `source_bom_id`。历史全部 BOM 的产出物料去重纳入待分类产品；不猜测机型、配置或人工建档人。重复迁移不重复建档。原 BOM 入口仍能选择已有物料；尚未纳入产品时，在建 BOM 的同一个事务内建立待分类档案。库存、历史工单需求、原 BOM 正文与版本不改写。

## 操作流程

1. 新增产品，或将原有物料纳入产品；按需建立产品系列并填写配置名称。
2. 左侧选择产品系列，右侧选中产品即可查看关联 BOM；产品资料内也可定位同系列产品。新建 BOM 时带入产出物料，组件与基准数量使用原公共单据编辑器。
3. 从非取消的 BOM 选择“复制派生”，保留来源版本，编辑目标产品、基准数量及完整组件后保存为新的草稿。修改目标产品即可跨产品复制；保持目标产品即可新增该产品版本。
4. 同一产出物料仍只能有一个启用版本。草稿启用、启用版本停用及草稿取消继续使用原 BOM 权限与规则。
5. 在 BOM 详情核对用料，点击“创建生产工单”进入预选版本的工单草稿；仅启用版本、实时创建权限且联网时允许。建单意图消费一次，刷新不会反复打开或重置输入。

产品页与原生产 BOM 页面共用 `BomEditor.vue` 和 Pinia 草稿。BOM 编辑器可快捷新建产品，保存后只带回产出物料，保留已填写的组件和数量。收起后再次打开同一产品及来源沿用草稿；保存失败不关闭或清空。账号、实例或证书变化时清理草稿及读取结果；撤权、断线和迟到响应不能回填另一会话。

BOM 派生保存完整明细和固定来源编号，不动态读取来源组件。来源停用、新增版本或取消草稿不会修改已保存的派生内容；已取消来源不能再创建新派生。来源按钮可查看原产品和原版本。保留现有重复组件、自引用、循环引用、数量精度、单一启用版本和历史工单快照规则。

## 接口与权限

| 接口 | 行为 | 权限 |
| --- | --- | --- |
| `POST /api/v1/products/query` | 编码、名称、规格、机型及配置搜索，类型/机型筛选；返回 `items/total/page/page_size`，默认每页 20 条、最多 100 条 | `inventory.view` |
| `GET /api/v1/products/{id}`、`/{id}/changes` | 当前产品物料资料及产品变更记录 | `inventory.view` |
| `POST /api/v1/products` | `material_id` 与 `material` 二选一，原物料不可重复纳入 | `catalog.manage` |
| `PUT /api/v1/products/{id}` | 产品版本、原因必填；可带物料资料及物料版本联合编辑 | `catalog.manage` |
| `GET /api/v1/product-models`、`/{id}`、`/{id}/changes` | 机型目录、当前资料及修订记录 | `inventory.view` |
| `POST /api/v1/product-models`、`PUT /api/v1/product-models/{id}` | 机型建档、版本编辑与原因留存 | `catalog.manage` |
| `GET /api/v1/boms?product_material_id=...`、`GET /api/v1/boms/{id}` | 产品范围 BOM 或单个版本，包含固定来源摘要 | `production.view` |
| `POST /api/v1/boms` | 原载荷增加可选 `source_bom_id`，旧客户端省略仍兼容 | `bom.create` |

产品查询不返回 BOM 内容；产品详情界面只有在具备 `production.view` 时才另行读取。BOM 启用、停用、取消及工单创建仍分别检查既有权限。主进程只允许固定业务地址，联合物料输入复用原白名单和响应校验；所有业务读写使用 ORM。

## 验证与边界

后端测试覆盖联合建档与版本回滚、物料身份与库存保持、分页及字面搜索、角色越权、机型修订、重复迁移、同产品升版、跨产品派生、取消/失效来源、自引用、原工单快照。前端测试覆盖受限桥接、分页迟到响应、同账号刷新、跨实例与断线、失败草稿、快捷创建带回、派生复制独立性、真实公共弹窗及工单路由衔接。

本期不增加产品删除、停产/停售开关、自动 BOM 继承与合并、配置组合生成、多级生产联动或新的 MRP 算法。安装包发布、本机服务升级需另行执行；数据库迁移能力不等于已升级用户当前运行的服务。
