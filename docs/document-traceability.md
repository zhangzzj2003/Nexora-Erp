# 单据与批次溯源（本轮分支已验证，待合并）

销售、生产、完工、采购入库与销售出库各自保留独立单号。销售明细与工单通过数量分配关联，支持拆单、合单与备货；超出订单需求或工单产量时拒绝，分配有操作审计，完成或取消工单不能再改关系。

库存确认事务自动追加系统入库批次和先入先出出库分配；调拨、退料、销售退货与冲销沿用原批次。库存金额核算继续使用原移动平均成本，不混淆批次物流与财务成本。冲销仍按现有可用库存及业务依赖校验；系统分配优先回到原批次，已消耗时按可用库存 FIFO 分配，不增加物理批号限制。

历史存量只建立带“批次待补录”标记的系统余额，不声称恢复真实物理批号。当前系统批号代表确认入库来源，若仓库实物拣货顺序与默认 FIFO 不一致，须增加实际拣货批次录入再作为物理批次验收依据。

查询从销售订单、工单、出库、采购入库或批次开始，双向展开关联单据与数量关系。结果使用账号授权快照分页，不输出金额或客户联系方式。超过一千节点要求缩小起点，不能静默截断。数据库版本 48。

统一验证证据、分支保留方式及正式环境边界见 [本轮交付与验收](erp-batch-acceptance.md)。
