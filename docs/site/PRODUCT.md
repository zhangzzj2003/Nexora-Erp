# 官网产品背景

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

用户确认纯静态 HTML/CSS/JS + WebGL，GitHub Pages 为目标；当前提供 GitHub Pages 公开预览，README 顶部提供官网链接与可点击预览图；需求分支仍等待确认合并。

## Users

了解 Nexora ERP 当前能力的人，以及查阅启动、架构、业务边界、验证和构建说明的开发者。

## Product Purpose

提供真实的项目功能与进度介绍，让详细开发文档能以 HTML 阅读，中英文内容同步维护。

## Capabilities and Constraints

ERP 当前为单公司、多仓库、在线局域网模式；应用界面仅中文。网站没有业务登录或数据访问。已实现、开发中、计划的状态不得混用。状态基准保存在 README 与指南中。

## Brand Commitments

保留 Nexora/联光 ERP 名称、现有品牌资源与青绿识别色。用户要求更具高级感，并选择先出视觉稿再实现。

## Evidence on Hand

仓库 README、专题文档、已合并代码和关联开发会话。不存在可用于公开声称用户量、收入或生产验收完成的证据。

## Current Website Presentation

首屏定位为“联光 ERP · 面向企业内部的桌面 ERP”，保留品牌口号与浅色青绿视觉，以电子生产物料、跨业务来源追溯、业务与财务衔接解释实际价值。业务来源生成凭证草稿，独立审核后过账，不声称业务确认即自动过账。主按钮探索业务演示，次按钮查看核心能力，开发文档和源码保留在导航。

首屏加入两张真实界面卫星、物料 → 库存 → 生产 → 财务路径和随滚动推进的椭圆轨道；五张当前真实组件截图沿全页 WebGL 轨道逐站展开：工作台首页、物料管理、库存台账、生产成本、总账凭证。浅色完整布局统一 1800 × 1200，虚构电子控制板场景，标注“当前界面预览 · 示例数据”，支持大图与手机纵向阅读。卡片随滚动入场、中央展开阅读、离场轻退，轨道随阅读进度绘制，倒滚沿原路收回；暂停滚动不再自行流动。手机保留轻量入场，减少动态保持完整静态阅读。英文官网使用相同中文应用截图并说明应用语言边界。

上方截图取景使用独立浏览器会话，不连接正式服务，不访问真实业务数据，不代表原生桌面运行验收。下方三窗在官网 HTML 内直接展示项目风格的采购入库、库存台账与应收应付来源，构建时复用工作台和共享表格样式，业务字段为项目字号的 150%。不在访客页面启动完整应用、加载子窗口或业务路由；首帧已有只读内容。镜头随滚动连续推进到同一份 DOM 的对应明细，支持微控制器、电阻、电容逐项连线和聚焦查看。手机提供横向取景，减少动态直接呈现可读视图。“业务演示”保留原有可操作沙盒及状态，官网通过明确手动操作发布分支预览，主线自动发布保持关闭。

下方真实界面按物料逐项对照，连线直接落在采购入库明细、库存对应行和应付对应行。桌面保留真实应用的导航、标签和侧栏，在工作区内放大明细约 2.2 倍（同窗宽对比），使用三倍像素无损图，手机放大所选项的关键字段，完整原图仍可打开。可选择微控制器、电阻、电容，分别查看 200 / 2000 / 1000 个的数量链，以及 4000 / 400 / 400 元的应付来源；不是只连接三个共同的 #101 标签。图片加载失败时停止对应关联显示，保留错误说明和原图入口。
