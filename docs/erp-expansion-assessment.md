# ERP 后续模块评估与实施门槛

本文是后续需求的评估清单，不表示这些模块已经实现。每一项在业务规则确定后，仍须按独立需求分支交付接口、权限、页面、测试和文档。当前内部试用以单公司、多仓库和在线局域网服务端为边界；[实机验收清单](lan-host-acceptance.md)尚未全部完成。

## 本次代码盘点

截至 2026-10-06，本仓库已有物料分类、永久编码、标题栏、主题切换、工作台刷新及[库存预警](inventory-warnings.md)的按仓库阈值、版本修订和审计桌面闭环。第 60 版已有实物批次 ORM 数据基础、差额诊断、来源历史和现场补证桌面页；采购入库、其他入库与合格完工入库确认现可登记多批次，其他用途出库、采购退货、销售出库和仓库调拨可指定已有批次，盘点差异与库存调整可归入已有或新发现批次，销售退货可归回原出库批次或登记退货新批次，生产领料可指定来源仓批次并可按原批次冲销错误确认，退料可归回原领料批次或登记退料新批次，支持冲销的单据按原分配冲销，第 60 版时共 140 张静态模型表；第 61 版增加客户归属审计，第 62 版增加[供应商与仓库资料审计](master-data-audit.md)，第 63 版增加人工运行小时读数、按小时阈值的保养计划及计划审计；第 64 版增加售后维修工时留痕；第 65 版增加手工商机概率与可见范围加权预测；第 66 版增加生产领料整单冲销；第 67 版增加生产退料整单冲销；第 68 版增加库存预警服务端观测与事件留存，第 69 版新增银行流水勾对四张 ORM 表，第 70 版新增 CSV 导入批次表及流水来源列；第 71 版新增银行账户绑定审计、总账勾对及撤销、余额调节表与复核六张表，第 72 版新增银行期初未达项及核销四张表，第 73 版新增[总账凭证附件](journal-attachments.md)及追加式撤销两张表，第 74 版新增[售后附件](after-sales.md)及追加式撤销两张表，第 75 版新增[报价附件](customer-relations.md)及追加式撤销两张表，第 76 版新增联系人、跟进与商机附件及追加式撤销两张表，第 77 版新增设备与维护工单附件及追加式撤销两张表，第 80 版新增售后人工责任核定一张 ORM 表，第 81 版新增销售合同正文版本一张 ORM 表，第 82 版新增合同版本原件附件及撤销两张 ORM 表，第 83 版新增售后维修工时成本核价一张 ORM 表，现共 181 张。现有库存流水来源均已有批次处理路径；历史未识别期初已可记录现场补证；升级检查点之后的旧客户端未分配流水可逐笔、先入后出成对或多笔成组补证，无法判定检查点的更早流水、先出后入或跨仓物料的自动匹配及未来新增单据仍待处理。设备台账、日历与运行小时计划、独立审核/验收、停机和耗材来源见 [设备维护规则](equipment-maintenance.md)。首页继续复用原有模型，不新增首页表。

后端既有业务读写已统一使用 SQLAlchemy 声明式模型与 ORM 会话；结构迁移及初始化数据迁移、SQLite 连接事务配置、在线备份与完整性诊断保留必要的底层操作。这些例外不允许用于业务 CRUD，范围见 [ORM 清单](backend-orm-migration.md)。

售后实际工时现可由财务人员按有依据的内部标准小时成本逐条核价与撤销，保留历史、缺口和期末归档；未核价不当作零成本，核价不生成工资或总账来源。维修单现可汇合已结案服务费、有效工时核价及耗材库存计价，显示可追溯的直接成本与直接毛利；缺价或未结案时不计算毛利，期末固定证据并隔离内部成本权限。税费、间接费用及工资凭证等未归集，完整维修项目利润仍待实现。

[首页经营统计](home-statistics.md)已接入真实业务净额、逐日来源、有效单据和当前待办/库存，按原有业务权限返回。MRP 已有物料级安全库存参数；按仓库的库存预警已有独立页面、桌面窗口内的定时状态变化提醒、失焦时的系统通知、托盘进程运行时的服务端事件轮询，以及服务端定时观测与事件历史；完整经营分析、服务端主动消息推送与通用消息调度仍未实现，不能将该快照视为正式总账报表。

公司财务报表已提供项目/科目配置、资产负债和利润查询、来源证据、CSV、配置审计、关闭期间归档和桌面独立权限入口，详见 [报表规则](financial-statements.md)。这属于公司项目编制能力，不能等同于税务申报、法定模板或业务方实机验收。

辅助核算已提供四类归属、版本规则、拆分期初、组合结转、辅助余额和来源核对，见 [辅助核算规则](auxiliary-accounting.md)。[历史分户期初](subledger-openings.md)另行提供逐笔原单、逐完整组合勾稽、独立审核、后续资金及凭证来源；这些能力不等同于完整项目管理、人力资源或银行直连。

主要未交付范围：

- 财务：已有[人工银行流水逐笔勾对与 CSV 导入](bank-reconciliation.md)；运行中补导、多控制科目、跨原单核销、税费、多币种、银行直连与利润分配仍待补，法定报表格式、现金流量及附注需另定规则。
- 供应链与成本：未来新增库存单据的实物批次接入、无法判定升级边界的旧流水与上下游真实来源追踪（[数据基础及设计草案](physical-lot-tracing.md)）、完整采购价差分摊、在制品与跨期成本。
- 生产与质量：有限产能排产、完整质量管理及售后深化；[不合格品处置与返工](quality-rework.md)基础闭环已提供。
- 业务扩展：销售订单明细保修条款已可自动带入售后，人工责任核定已追加留痕；合同原件留存已提供；签署验证、责任自动判定、序列号、工时成本总账归集与维修项目完整利润仍待深化，CRM 营销/预测模型/对外发送/调度深化、设备自动采集遥测/维修采购、人力资源，以及通用审批流程；已批准报价 PDF 导出和设备维护附件已提供。
- 组织与数据：多公司/分公司边界、MySQL、离线同步及冲突处理。
- 运行验收：Windows/macOS 组合实机、无人登录重启、升级与备份恢复演练。

单公司、人民币、移动加权平均成本作为已确认初版规则；不据此推断上述未确定模块的制度已获确认，联系人、跟进、商机与批准报价转销售草稿已提供，但不把它们、基础质检或操作权限算作完整 CRM、质量管理或审批引擎。

## 建议的需求顺序

以下顺序是**候选实施顺序**，不是已确定的会计政策。先由业务负责人确认样例单据、期初数据和核对口径，再为每个具体需求建分支。

1. **成本与业务金额基础。** 确定采购价差、历史无价单据的补价权限、库存计价方法、退货沿用成本规则，以及生产在制与完工批次的分摊口径。先让库存数量、库存金额、工单成本和销售成本可从原始单据相互追溯；缺价时明确显示待核价，不能默认为零。
2. **总账与凭证。** 科目和期间基础资料已交付，详见 [总账基础规则](ledger-foundation.md)；正式期初独立审核确认见 [期初余额规则](opening-balances.md)，历史未结单据逐组合核对见 [分户期初](subledger-openings.md)；总账凭证附件已提供，跨原单核销仍待补；[银行流水勾对与余额调节规则](bank-reconciliation.md)已提供人工逐笔勾对、CSV 导入、总账分组勾对和独立复核。手工凭证已提供借贷平衡、独立审核、过账和冲销，见 [手工凭证规则](manual-journals.md)；[业务来源凭证](business-journals.md)已提供映射、重复生成保护和来源快照，仍须独立审核过账。现有收付款由人工登记，银行流水由操作员逐笔登记或上传文件，勾对结果不能证明银行原始凭据真实。
3. **结账与财务报表。** 期间结账、历史核价/分摊锁定、倒序重开和归档已提供，见 [期间结账规则](period-closing.md)；[损益结转](profit-transfers.md)已提供期间末草稿、独立审核、来源保护和倒序更正。已过账科目明细与试算平衡已提供，见 [总账报表规则](ledger-reports.md)；[公司财务报表](financial-statements.md)已提供项目映射、资产负债/利润查询、来源下钻和固定归档；辅助核算已提供，见 [辅助核算规则](auxiliary-accounting.md)；继续设计现金流量和法定模板。报表金额要能下钻到凭证及原始单据；未结期间和缺价单据需显式标注。未形成可核对的总账前，不把业务汇总称为正式财务报表。
4. **质量、售后和 CRM。** [不合格品处置与返工来源](quality-rework.md)已提供，[售后退换修](after-sales.md)已提供原出库关联、独立审核、客户物品保管、检验交付和明确收费；实际维修工时与附件已留痕，销售订单明细保修条款可沿出库自动带入售后并按固定申请日核对，旧订单未知条款仍可人工登记；人工责任核定已留痕，[销售合同正文与修订历史](sales-contracts.md)已提供追加式证据；合同原件已可按版本留存，签署验证、责任自动判定、序列号、工时成本总账归集与维修项目完整利润待补。[客户关系与报价](customer-relations.md)已复用现有客户资料并提供联系人、跟进、商机及固定报价独立审核转单；手工概率与加权预测、联系人/跟进/商机/报价附件留存与撤销已提供，后续营销、预测模型深化及消息调度另定规则，避免出现第二套客户主数据。
5. **审批、设备、经营报表与人力资源。** 审批先选一个真实单据及金额阈值试点，并保持服务端权限校验。[设备维护](equipment-maintenance.md)已提供台账、日历与人工读数触发的小时保养、独立审核验收、停机、耗材关联与附件留存；自动采集遥测、维修采购及资产财务另定规则。经营报表复用同一套已确认业务单据。人力资源涉及独立的人员权限和保留期限，先确定数据责任人及访问边界。

## 多公司与分公司设计门槛

目前数据库和权限均按单公司运行。增加组织维度前，先用真实业务样例逐项回答：物料与往来单位由谁维护、哪些仓库可被哪个组织使用、订单和库存流水归属哪个组织、用户可查询哪些组织、跨独立公司是否需双方各自确认单据。共享资料不等于共享库存或共享财务余额；跨公司交易需要双方可审计的单据与冲销关系。未确认这些边界前，不直接给现有表批量增加公司字段。

## 每个后续需求的验收门槛

- 提供至少一条完整正常流程和一条更正或冲销流程，写明谁有权操作、何时确认、如何追溯原单据。
- 金额变动在服务端事务内核对数量、状态、权限与并发；对缺价、重复确认、余额不足和跨期更正有明确结果。
- 前后端共享类型、接口错误语义、页面、单元测试及文档同步；真实桌面与设备验收分别记录，不用构建通过代替。
- 财务报表和跨公司功能上线前，使用业务方提供的期初数据与对账样例做结果核对；本仓库目前没有这些验收样例。
