# 生产与质量完善（开发分支，待统一验证）

- 物料计划使用已确认销售的未分配需求、未完成工单的净需料。销售需求展开最新启用多级 BOM，已有工单保留原快照；拒绝循环及过深层级。抵扣本仓库存、公司采购在途、未转订单的有效采购申请。安全库存及提前期按物料、仓库版本化维护。缺料可生成采购申请草稿，重新计算后没有缺口时拒绝重复生成。
- 工作中心按单资源安排工序，统一保存 UTC 时间，端点相接允许、时间重叠拒绝。编辑使用版本校验，取消保留历史及原因。目前为人工排程，不宣称自动优化或完整车间执行系统。
- 已确认不合格数量可分批报废或返工，写事务防止重复处置。返工另建独立工单，引用原完工单；只添加明确的替换料，不重复领原 BOM 全部原料。新返工工单继续采用现有报工、质检及入库流程。已处置完工单不可冲销。
- 成本结算须先处理全部不合格数量；按报工数量比例区分合格入库、报废及返工成本，累计分摊保留尾分。全不合格没有虚拟成品入库，仍可结算到质量成本。返工承接原分配成本，父结算通过依赖关系锁定；未结算原成本时，返工成本明确为未知。
- 在制成本按截止日业务范围与现有核价重算，显示累计成本、已转成品及质量成本、返工承接和缺价项。期间结账保留该查询证据，不把在制成本自动生成总账凭证。
