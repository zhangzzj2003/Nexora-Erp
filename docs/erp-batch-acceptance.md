## 正式环境与业务边界

本轮未升级公司的已安装服务端，也未修改公司业务数据库。客户端与服务端须一起升级，数据库最终版本 50；正式部署前使用现有备份/升级流程，管理员需要分配历史客户。现场数据、真实期初与资金样例、实物拣货批次、跨平台局域网及无人登录启动仍需独立验收。

系统批次依据确认流水及 FIFO 推断，不声称恢复历史物理批号。衍生成本和财务汇总需要完整范围计算，再分页返回；普通单据列表在 SQL 查询中先分页，不能把“分页传输”描述为全部计算量都与单页大小相等。

财务本轮提供人民币基础及管理核对，没有法定报表模板、多币种或银行直连；银行匹配是一条流水对应一笔有效收付款。人工排程按单资源检查重叠，尚未提供自动产能优化。完整 CRM 商机、售后、设备、人力和多组织继续保留计划状态。
