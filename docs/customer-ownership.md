# 客户归属与销售金额权限

本轮开发分支实现客户档案编辑、停用、商务归属、管理员转交及版本审计。已完成本轮统一自动检查和临时桌面验收；正式服务端尚未升级。

客户完整资料仅负责人和内置管理员可读；共享销售订单仅展示必要客户名称、物料、数量与进度。`customer.view`/`customer.manage` 与 `sales.view` 分离。新建客户默认本人负责，管理员可分配；历史客户待分配。非管理员不能通过请求参数冒领或转交客户。被业务使用的客户通过停用处理。

订单负责商务独立保存，代办人与负责人不同；客户转交不改变历史订单金额权限。负责人、管理员、获 `sales_amount.all` 授权的岗位可读单价及金额。未授权的销售订单和退货响应以 `amount_visible=false`、金额 null 脱敏，数量继续可见；财务、总账和结账证据的读取还需全部销售金额授权。内置财务员默认获该授权。

管理员可独立移交订单；档案编辑和两种转交携带版本与原因，并在同事务中保存审计。越权访问客户返回统一 404，不暴露存在性。历史审计对非管理员不返回旧私有快照。

数据库第 46 版增设归属表和审计表；客户端和服务端须同步升级。新增路由 `/api/v1/customers/{id}`、`/{id}/history` 和 `/orders/{id}/owner`。客户列表及审计已接入统一服务端分页。

统一验证证据、分支保留方式及正式环境边界见 [本轮交付与验收](erp-batch-acceptance.md)。
