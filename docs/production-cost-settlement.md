# 完工成本结算规则

当前规则适用于单公司、人民币、全部仓库按物料计算的移动加权平均库存。这里只记录已实现的工单成本结算，不替代总账期间结账。

## 材料与费用

- 已确认领料优先采用该流水发生时的库存平均成本。退料沿用原领料成本，工单材料金额按净领数量乘原成本、逐明细四舍五入到分。
- 库存价格未知时，财务员可按凭据人工核定领料单价。库存已有有效价格时不可另行覆盖。人工核价记录保留；库存价格形成后，未结算工单优先采用库存成本，并明确显示旧人工记录是否仍被采用。
- 人工、制造费用仍由财务员按工单登记。所有净领料必须有价格，未知成本不按零处理。没有录入费用表示当前登记金额为零，业务方仍须核对实际费用完整性。

## 结算与分摊

工单全部目标报工确认后，处理或取消未确认的领料、退料及报工草稿。财务员在生产成本页填写外部或内部结算依据编号；业务单号仍由服务端自动生成。服务端在一个写事务内核对状态、净领料价格和费用，保存预计材料来源、费用与分摊草稿。草稿与审批批准均不改变正式库存计价、不锁定来源；须独立批准后通过带原生版本的确认操作正式执行。执行再次复算全部金额、数量与来源，变化返回冲突，须撤回并取消旧草稿，按新依据重新建单。

新结算要求不合格数量全部确认处置，按明确选定的正常报废、独立损失或返工携入规则分配；公式、全部不合格与未知携入约束见 [不合格品处置与返工](quality-rework.md)。历史结算快照保持原口径，不自动推断处置。没有不合格数时仍按**合格完工入库数量**分摊。分摊按完工单顺序计算累计比例金额，相邻累计额相减，保证尾分不会丢失且所有批次金额精确合计到结算总额。例如总成本 7.70 元、三个等量批次，分摊为 2.57、2.56、2.57 元。

仅已正式执行且未冲销结算的分摊金额用于原完工入库流水的库存计价。内部保留精确金额及 Decimal 单价，四位单价仅供展示。后续成品销售或再次生产领料使用相应移动平均成本；补结算会重算尚未形成期间锁定的历史库存金额。

## 更正与审计

有效结算冻结本工单费用、完工来源及引用的库存核价来源（包括人工领料核价所依赖的未知库存来源）。修改前必须填写原因并另行独立审批冲销；原执行人员不能批准自己的更正，执行只接受本次批准的固定原因。更正材料、费用或完工后，以新的依据编号重新建立待审结算；旧结算、分摊、原费用及冲销记录始终保留。

成品已被后续工单领用并结算时，先冲销后续结算，再冲销来源工单结算，避免下游已结算成本与上游来源不一致。冲销结算不改库存数量；原完工数量更正仍走完工单冲销并检查实物库存。

## 已知边界

会计期间关闭已锁定历史核价与完工分摊，见[期间结账](period-closing.md)；[业务来源凭证](business-journals.md)已提供采购价差、生产成本及销售成本分录，仍须独立审核过账。完整采购价差分摊、在制品跨期分摊尚未实现；生产不合格品返工成本已提供。成本批次以完工单为单位，没有实现实物批号/序列号追踪；[物料需求计划](material-planning.md)提供数量与日期建议，不改变这些成本边界。真实期初数据与现场成本核对仍需业务验收。

数据库第 93 版沿用旧正式结算金额、原时间、业务号及分摊，补充原生执行状态，审批历史不补造。取消预计草稿保留编号、计划及理由；同工单原有依据编号的永久防重复约束保留。结算、审批执行事件、计价与来源锁定同事务提交，失败全部回滚。
