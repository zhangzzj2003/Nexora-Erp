# 财务完善（开发分支，待统一验证）

- 采购、销售按行输入税率、折扣及报价是否含税。先折扣，再税价换算，保存四位含税结算单价；原报价及税率保留快照。已确认单据不支持改价。分批业务和退货沿用结算价。
- 往来期初有草稿、确认、作废及独立结算记录。确认前不可结算，不能超额或逆方向结算；已有结算不可作废。往来期初不自动生成总账，按选定往来科目与正式总账期初核对差额。
- 银行流水以唯一参考号导入，一次最多 100 行；整批失败回滚。银行入账为正、出账为负；收付款单按应收/应付及退款方向匹配。一个流水对应一笔有效收付款，不能重复匹配；冲销前先解除匹配。所有处理保留审计。
- 手工凭证可录入客户、供应商、部门、项目维度。单位名称保存快照，冲销复制维度，辅助账仅统计已过账分录。
- 管理资产负债和利润表以正式期初及已过账凭证为依据。资产包含未转入损益的成本余额；利润排除损益结转及其冲销。列出试算平衡与资产负债差额。科目类别决定管理报表归类，这不是预置法定报表格式。
- 查询结果按账号授权创建短期快照，表格分页及 CSV 导出使用相同结果。人民币为本期实现范围；多币种、自动业务凭证扩展仍保留原计划状态。

本轮没有提前执行测试、类型检查或构建；统一验证在所有需求编码结束后执行。数据库版本 47。
