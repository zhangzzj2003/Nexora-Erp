# 表格分页与按需刷新

本轮开发分支使用 `/api/v1/tables/query` 固定数据集白名单。服务端在同一读事务中先做权限范围、字面搜索、稳定排序、总数及页码回退，再仅序列化当前页；默认 20，最大 100。用户资料通过受限序列化器返回，绝不暴露密码或会话表。客户总数、搜索与明细读取均在负责人范围内执行。

`WorkspaceTable` 对已保存记录使用服务端数据集；尚未保存的表单行留在本地并分页显示。各业务列表、已保存财务明细与审计使用固定查询。选择框远程搜索，支持继续加载下一页，保留当前值及空选项。写入后更新刷新版本，只由当前挂载表格查询；不再于每次登录或保存后读取全公司业务记录。跨账号或权限变化会阻止旧请求回填。

库存数量仍以 Decimal 汇总；衍生成本、期初、累计余额及汇总按完整范围计算，分页仅决定返回行。报表与台账的浏览器请求启用短期查询快照，分页及 CSV 同来源；只有点击导出才传输完整 CSV。快照绑定账号、角色与权限，最多 32 份、单份 8 MiB、900 秒，失效明确要求重查，服务重启不伪造恢复。

旧接口暂保留供兼容和内部计算；新页面必须使用分页数据集。新数据集需明确权限、公开序列化、筛选与排序字段，不能接受任意表名或 SQL。当前实现尚待本轮全部任务结束后统一验证，不标为已交付。
